# Biologie-Unterricht

Sammlung digitaler Unterrichtseinheiten (HTML) für den Biologie-Unterricht.

- `index.html` – Startseite mit allen Einheiten, sortiert nach Jahrgangsstufe
- `style.css` – gemeinsame Gestaltung
- `einheiten/` – je Einheit ein Unterordner, z. B. `einheiten/thema-jg7/index.html`
